RUANG KATA — WEBSITE MEMBACA DAN MENULIS NOVEL

Cara menjalankan:
1. Ekstrak folder project.
2. Buka folder di Visual Studio Code.
3. Install ekstensi Live Server.
4. Klik kanan index.html lalu pilih Open with Live Server.

Fitur:
- Jelajahi novel dengan kartu sampul foto berdasarkan genre.
- Cari dan filter novel.
- Buat, simpan draf, terbitkan, edit, baca, dan hapus novel.
- Data karya pengguna disimpan di localStorage browser yang digunakan.

Catatan gambar:
Sampul contoh memakai gambar online dari Unsplash sehingga perlu koneksi internet untuk memuat gambar. Jika ingin memakai foto sendiri, tambahkan file ke folder images dan isi properti cover di data novel dengan path seperti "images/sampulku.jpg".

Catatan sistem:
Ini adalah prototipe front-end. Novel yang dibuat hanya tersimpan di browser/perangkat ini. Untuk akun dan publikasi yang dapat dilihat semua pengguna, diperlukan backend, database, dan autentikasi.
